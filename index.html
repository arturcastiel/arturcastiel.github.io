My research covers non-orthodox flux approximations and multiscale finite volume methods, applied to hydrogen storage, carbon capture & storage and enhanced geothermal systems. I am also an active contributor to the Open Porous Media (OPM) initiative.

Simulators

Open Source · Contributor

Open Porous Media (OPM)

OPM is a community-driven open-source initiative for simulation of porous media processes. I contribute to its core modules (opm-common, opm-grid and opm-simulators) with 80+ merged pull requests, working on Local Grid Refinement (LGR), compositional flash calculations and dual-porosity models. I am a credited author of the OPM Flow 2026.04 release.

Open Source · Former Main Developer

DARSim

DARSim (Delft Advanced Reservoir Simulator) is TU Delft's open-source MATLAB reservoir simulator for multiphase flow in porous media, now aimed at CO₂ and hydrogen storage. It uses fully implicit finite volumes with algebraic dynamic multilevel (ADM) methods and pEDFM fractures. I was one of its main developers; the project now continues under the ADMIRE group, where I am listed as a contributor.

  • MATLAB
  • Reservoir Simulation
  • Multiphase Flow

Creator · Lead Developer

IMPRESS

The Intuitive Multilevel Preprocessor for Smart Simulation (IMPRESS) is a Python pre-processor designed to make multiscale and multilevel simulation straightforward. It features a hierarchical data structure where mesh information is encapsulated and coarse volumes are components of the high-resolution mesh object.

  • Python
  • NumPy
  • Multiscale Methods

Libraries and guides

Author · Python library

cpg2unstructured

Turns an Eclipse corner-point grid (text GRDECL or binary EGRID) into a clean unstructured mesh plus a cell-to-cell adjacency graph. It handles faulted grids with non-matching pillars, pinch-out non-neighbour connections and disconnected reservoirs, on a pure NumPy core.

  • Python
  • NumPy
  • SciPy (optional)
  • Corner-point grids
